(a) Why called Break-even inflation? Remember,
• TIPS nominal yield = TIPS real yield + actual inflation rate.
• Treasury nominal yield = TIPS real yield + breakeven rate (expected inflation)
If actual inflation > breakeven rate → TIPS outperform nominal Treasuries → arbitrage
If actual inflation < breakeven rate → Nominal Treasuries outperform TIPS → arbitrage
If actual inflation = breakeven rate → Both give the same real return → indifferent

(b) Why Break-even inflation ≈ Expected future inflation?
Because it reflects the market’s consensus forecast for future inflation.
• If investors expect (future) inflation > breakeven rate, they buy TIPS/sell Treasuries,
   pushing breakeven rate up to match expectations, vice versa.

§ Summary & Key Takeaways

讲义原文

Summary & Key Takeaways

Summary & Key Takeaways

• The yield curve shows interest rates for different bond
  maturities.
• Its shape helps predict economic trends like growth or
  recession.
• Three main factors drive yield curve movements: level, slope,
  and curvature.
• Central banks use tools like QE, YCC, and forward guidance to
  influence the curve.
• The yield curve is a key indicator, influencing and reflecting
  growth, inflation, and financial stability.
