模块 0 · 导论：如何使用讲义原文+解析对照

本模块无对应单份幻灯片；说明如何使用「左讲义原文 / 右解析」双栏学习法。
左侧：讲义原文（英文为主，保留术语） 右侧：零基础解析（中文 + 公式 + 易错点）

怎么用这个站点

  1. 先扫右侧解析，建立直觉；再读左侧原文，对齐老师课件用语。
  2. 桌面端两栏并排，可各自滚动；手机端变为「先原文、后解析」的区块堆叠。
  3. 每学完一个模块，底部打卡；首页进度条会更新（存在本机浏览器）。
  4. 遇到生词，打开 术语表；术语也会在讲义原文栏原样出现。
学习顺序
模块 1→3 打地基（工具、定价、收益率）→ 4→6 认识市场产品 → 7→8 曲线与零息构造。不要跳过 2/3 直接啃 8。

你会反复用到的三个直觉

  • 利率 ↑ → 旧债价格 ↓
  • 票息率 ≠ 收益率（除非大致平价）
  • 多出来的收益，通常买的是某种风险（久期 / 信用 / 流动性 / 汇率）
