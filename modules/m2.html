模块 2 · 债券怎么定价

核心公式：价格 = 未来现金流的现值之和

普通固息债（vanilla bond）每期票息 C，共 n 期，到期还面值 M，每期折现率 r（例如年化收益率/2）：

P = Σ C/(1+r)^t + M/(1+r)^n = C × [1 − (1+r)^(−n)] / r + M/(1+r)^n

直觉：钱今天比明天更值钱；越晚到的现金流，折得越狠。

日常类比
定价像「点外卖预付」：你愿意为「一年后到的 100 元红包」付多少？若你心里的机会成本是每年 5%，你大概只肯付约 95 元——这就是折现。

票息 · 价格 · 收益率三角关系

Yield：使未来现金流现值刚好等于当前市价的那个利率。市场先给你价格，你反推 yield。

关系价格直觉
票息率 < 收益率折价（Price < Par）债「不够香」，必须打折卖
票息率 = 收益率平价刚好符合市场要求
票息率 > 收益率溢价债「太香」，大家抢着溢价买

价格与收益率反向，且关系是凸的（convex）：收益率同等下降带来的涨价，往往大于同等上升带来的跌价。

迷你算例（讲义风格数字）
面值 1000，年票息 5%（每年约 50）。若市场要求 6% 的 yield，价格会落到面值以下（讲义示意约 925 量级）。
反过来：7% 票息 vs 6% yield → 溢价（示意约 1075）。

价格为何随时间变？

  1. 信用变化：发行人变差 → 要求更高 yield → 价格跌。
  2. 向面值收敛（Pull-to-Par）：即使收益率不变，折价债会慢慢涨向面值，溢价债慢慢跌向面值——因为到期必须兑付面值。
  3. 市场利率变化：整体收益率上移/下移。

浮息债与反向浮息债（入门）

Floater：票息 = 参考利率 + 利差（spread）。参考利率如 SOFR（替代 LIBOR）、€STR、中国 LPR、联邦基金目标利率等。若市场要求的利差≈债券利差，价格常接近面值。

Inverse floater：票息 = 常数 − 参考利率。利率升时票息降，风险很大。交易商常把一只固息债拆成「浮息 + 反向浮息」；无套利下：抵押品价格 ≈ 浮息价格 + 反向浮息价格。

干净价与脏价

Dirty Price（全价/发票价）= Clean Price（净价）+ Accrued Interest（应计利息）

报价常见净价；真正交割付钱按脏价。应计利息 ≈（距上次付息已过天数 / 付息期天数）× 当期票息。

计日惯例：国债常用 Actual/Actual；公司债/市政债常用 30/360。

国债报价还有「32 分之几」传统：如 99-16 = 99 + 16/32 = 99.50。

应计利息例（讲义）
年票息 6%，半年付息 30；上次付息 3/1，交割 7/17，下次 9/1。
30/360：AI = 136/180 × 30 ≈ 22.67
Actual/Actual：AI = 138/184 × 30 ≈ 22.5
容易混淆
报价看到的是 Clean Price，但你账户扣的是 Dirty Price。另：Yield ≠ Coupon Rate——这是全课最高频坑。

自测题（点开看答案）

Q1. 净价 985、应计利息 12，买方实付（脏价）多少？
答：997。
Q2. 票息 5%、yield 6%，价格相对面值？
答：折价（Price < Par）。
Q3. Pull-to-Par 指什么？
答：随到期临近，价格自然向面值靠拢。
Q4. 浮息债票息一般怎么写？
答：参考利率 + 利差（spread）。
Q5. 国债报价 99-16 的小数价格约是多少？
答：99.50（99 + 16/32）。
