模块 3 · 收益率怎么算

Yield = 投资的内部收益率（IRR）

找一个利率 y，使所有现金流折现之和等于买入价 P：

P = Σ CF_t / (1+y)^t

零息债有闭式解：y = (CF_n / P)^(1/n) − 1。附息债一般靠试错/数值方法。

年化：名义年化 ≈ 周期利率 × m；有效年利率 EAY = (1+y_per)^m − 1。

日常类比
Current Yield 像「房租收益率」= 年租金/房价，只管当下现金；YTM 像「整段租约的总账」——还要把到期卖房盈亏、租金再投资算进去。

常见收益率指标速查

指标在算什么
Current Yield年票息 / 现价；忽略资本利得与再投资
YTM持有到期的总回报假设（含票息、价差、再投资于 YTM）
YTC / YTP假设在赎回日/回售日结束
YTWYTM、YTC、YTP 等中最差（最低）的那个
Cash Flow Yield用于 MBS/ABS 等提前还款不确定的现金流

折价债：Coupon < Current Yield < YTM。
溢价债：Coupon > Current Yield > YTM。
平价：三者大致相等。

Current Yield 例（讲义）
年票息 50，价格 900 → Current Yield = 50/900 ≈ 5.56%。若持有到期还能赚回面值差额，YTM 会更高（讲义示意约 6.2%）。

组合与浮息债

组合收益率不是各券 YTM 简单平均，而应合并全部现金流，再对总市值解一个 IRR。

浮息债常用 Discount Margin（DM）：假定参考利率不变，找一个利差，用「参考利率+利差」折现，使现值=市价。平价且利差 80bps 时，DM≈80bps。

总回报与持有期（Horizon）分析

债券回报三来源：票息 · 资本利得/损失 · 票息再投资（利息的利息）。

YTM 假设：持有到期 + 票息按 YTM 再投资。现实常提前卖出、再投资利率变化——于是用 Horizon Analysis：

  1. 算持有期内票息及再投资的终值；
  2. 估计期末卖出价（用当时预期收益率折现剩余现金流）；
  3. 总终值与期初价格反推持有期收益率。
持有期算例（讲义改编）
面值 1000，票息 6%（年付 60），买价 970，持有 3 年，再投资利率 4%，预计卖出时收益率 5%。
票息终值 ≈ 187.30；卖出价 ≈ 1018.59；总终值 ≈ 1205.89。
解 970(1+y)^3 = 1205.89 → y ≈ 7.53%/年。
注意：短持有期表面收益率可能更高，但波动也更大；「提前卖出锁定高收益再重复」现实中有再投资风险、交易成本，且事前并不确定。
容易混淆
YTM 不是「保证到手的收益率」。它内嵌再投资假设；若你中途卖出或再投资利率改变，实现总回报会偏离 YTM。

自测题（点开看答案）

Q1. 折价交易时，票息率与 Current Yield 谁更高？
答：Current Yield 更高（年票息/较低市价）。
Q2. 哪个指标把持有到期的票息+资本利得一起考虑？
答：YTM。
Q3. 组合 YTM 能否对各券 YTM 取简单平均？
答：一般不能，应合并现金流再解 IRR。
Q4. 浮息债常用什么代替传统 YTM 表述？
答：Discount Margin（折现利差）。
Q5. Horizon analysis 比 YTM 多考虑了什么现实因素？
答：持有期长度、再投资利率、期末卖出价格（市场收益率变化）。
