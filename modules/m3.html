3. Yields for Portfolios & Floaters

Yield for Floaters – Part 1

For Floaters, Discount Margin (DM) is used instead of YTM (why?):
We find the discount margin in the following way:
① Assume reference rate is constant
② Try a margin (e.g., 96 bps)
③ Discount cash flows using (reference rate + margin)
④ Adjust margin iteratively until PV = price

Example: If a floater priced at par with spread 80bps, DM = 80bps

4. Total Return and Horizon Analysis

3. Yields for Portfolios & Floaters

4. TOTAL RETURN & HORIZON
ANALYSIS

4. Total Return and Horizon Analysis
Think of the three sources of bond return:

      Coupon interest   Capital gain/loss   Reinvestment income
                                            (interest-on-interest)
Example
3-Year Bond, Face value: $1,000, Coupon: 6% annual = $60/year,
Purchase price: $950, Held to maturity, Reinvestment rate: 5%. Then
• Coupon income = $60 *3 =180
• Interest-on-interest = 60 × 1.05 2 + 60 × 1.05 1 + 60 − 180 = 9.15
• Capital game = redeemed price–buy price = $1000-$950=$50
解析

Horizon analysis / total return：在给定持有期、再投资利率、期末卖出收益率假设下，估算实现总回报。

YTM 假设「持有到期 + 票息按 YTM 再投资」；一旦提前卖出或再投资利率不同，实现回报会偏离 YTM。

Total future value = 再投资后的票息累积 + 期末卖出价；再换算持有期收益率

4. Total Return and Horizon Analysis

4. Total Return and Horizon Analysis
Total Return

Definition:
 Total Return = Coupon income + Reinvestment of coupons + Resale Price

Total return reflects the realized return on a bond over a specific
holding period, not necessarily to maturity, factoring in:
1. Coupon income
2. Reinvestment of coupons for a given reinvestment rate (may not
    be YTM)
3. Resale price at the end of the horizon (which may differ from face
    value)
解析

常见指标：Current Yield（年票息/市价）、YTM、YTC（按赎回价与赎回日算）、Yield to Worst、现金流收益率等。

Summary & Key Takeaways

Summary & Key Takeaways

• Yield (IRR) discounts cash flows to match bond price.
• Current Yield is coupon/price; YTM includes total return.
• YTW is the worst-case yield (lowest of YTM/YTC/YTP).
• Discount bonds: YTM > Current Yield > Coupon Rate.
• Total Return combines coupons, reinvestment, and price changes.
• Horizon analysis calculates realized returns incorporating
  reinvestment rates and changing market yields.
• Short-term holders face more volatility than long-term investors.
