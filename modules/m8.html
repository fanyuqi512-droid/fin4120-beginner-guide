模块 8 · 零息曲线怎么来

问题：市场上多为附息债，如何得到零息利率？

零息收益率（即期利率）是给「单一未来现金流」定价的利率。有了整条零息曲线，才能一致地给任意债券/衍生品折现。思路：从一篮子干净、可比、有流动性的国债价格反推折现因子。

日常类比
你只知道「套餐价」，想知道每一道菜单独多少钱。Bootstrap 像按顺序拆套餐：先用单点菜（短债）定价，再从双人套餐里扣掉已知菜价，解出第二道……间接法则像假定「菜单价格符合一条平滑曲线」，一次拟合所有套餐。

第 0 步：挑「干净篮子」

保留：普通固息、价格正常、有成交。剔除或审查：含权债、离群收益率、流动性极差的报价。错误的输入会污染整条曲线。

直接法 ①：线性方程组（理论）

若 n 只债券、支付日整齐对齐：价格向量 P = 现金流矩阵 F × 折现因子向量 B，则 B = F⁻¹ P。再把折现因子换成零息利率：

年复利：B(0,T) = 1 / [1+R(0,T)]^T → R = B^(−1/T) − 1 连续复利：R_c = −ln(B)/T
讲义方程组结果（建立直觉）
四只债解出：B(0,1)≈0.9619 → R≈3.96%；B(0,2)≈0.9119 → R≈4.72%；B(0,3)≈0.8536 → R≈5.42%；B(0,4)≈0.7890 → R≈6.10%。现实支付日很少这么整齐 → 需要 bootstrap。

直接法 ②：Bootstrap（逐步剥离）

  1. 用短端零息（如 T-bill）得到最近折现因子；
  2. 对下一只附息债：价格 − 已知票息的现值 = 最后一笔（票息+本金）× 未知折现因子；
  3. 解出下一折现因子/零息利率，重复。
B(t,T2) = [P − C·B(t,T1)] / (C+F)
迷你 bootstrap（自编简化，标注非讲义原表）
假设已知名义年化零息：1 年 = 5%。一只 2 年期年付息债：面值 100，票息 6，全价 101。
101 = 6/(1.05) + 106/(1+R2)^2
→ 101 − 5.714 = 95.286 = 106/(1+R2)^2
→ (1+R2)^2 = 106/95.286 ≈ 1.1124 → R2 ≈ 5.45%。
真实课堂例子会涉及 14 个月、21 个月等非整年期限，需数值求解（讲义得到如 5.41%、5.69%、5.79%、5.91% 等）。

直接法 ③：插值补洞

观测点之间需要填：对折现因子线性插值、对收益率线性插值、或立方样条（更平滑，利于远期利率）。线性简单但可能「折角」；样条更光滑但更复杂。

间接法：一次拟合整条曲线

Bootstrap 的痛点：缺点、误差会向后传播、对报价噪音敏感。间接法选一个带参数的平滑函数（样条折现函数、Nelson-Siegel 等），最小化「模型价格 vs 市价」的加权误差（常给短端更高权重）。

Nelson-Siegel 用少量参数描述水平、斜率、曲率——与模块 7 的 PCA 直觉相呼应，适合快速得到平滑曲线；代价是模型设定误差（形状错了会系统性偏）。

零基础记忆口诀
直接法 = 逐点拆解；间接法 = 整条曲线「试衣服」。先理解 bootstrap，再学拟合，就不会被矩阵吓跑。
容易混淆
YTM 曲线 ≠ 零息曲线。单只附息债的 YTM 是「一个 dig 到底」的平均利率；零息曲线才是每个到期日自己的即期利率。用错曲线会导致定价不一致。

自测题（点开看答案）

Q1. 为什么不能直接把所有附息债的 YTM 连起来当零息曲线？
答：YTM 混合了多期现金流，不是单一到期即期利率。
Q2. Bootstrap 的基本动作是什么？
答：用已知短端折现因子剥离下一期未知折现因子。
Q3. 插值的目的？
答：在没有直接报价的期限上补全曲线。
Q4. 间接法相对 bootstrap 的主要优点？
答：一次拟合、更平滑、对个别报价噪音更稳健（但有模型风险）。
Q5. Nelson-Siegel 大致在刻画曲线的哪几类形状特征？
答：水平、斜率、曲率。
